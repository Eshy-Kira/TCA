Jogo de Lógica
O projeto consiste no desenvolvimento de um jogo de raciocínio lógico inspirado no Teste de Einstein, no qual o jogador precisa solucionar um desafio envolvendo cinco casas e diferentes características.
O objetivo é descobrir a combinação correta entre cores, bebidas, nacionalidades, animais de estimação e estilos musicais, utilizando as pistas disponibilizadas pelo jogo.
O programa permite consultar as charadas, selecionar as características de cada casa, visualizar as escolhas realizadas e verificar a quantidade de acertos ao finalizar o desafio. Também possui um sistema que impede a repetição de características entre as casas e oferece a possibilidade de jogar novamente.
O jogo foi desenvolvido em JavaScript, utilizando conceitos como variáveis, estruturas condicionais, estruturas de repetição, funções, classes, objetos e arrays.
